# Viewer

## Launch

- EXE: `RpgMakerImageViewer.exe`
- Command line / double-click association: open an image path
- Tray host with File / View / Help menu window

## Menu (Cursor-style top bar)

### File
- 打开图片… (`Ctrl+O`)
- 打开文件夹… (`Ctrl+Shift+O`) — 预览该文件夹下第一张可识别图片，左右键切换同目录
- 关闭窗口 (`Esc`) — tray mode hides to tray

### View
- 适应窗口 (`Ctrl+0`)
- 预设比例：实际大小 100%、25%、50%、75%、150%、200%、400%
- 放大 / 缩小 (`Ctrl++` / `Ctrl+-`)
- 鼠标滚轮缩放

### Help
- 关于软件
- 关于作者（含 GitHub：https://github.com/Forty40）

## Display

- Decrypt (or load plain PNG) and show with zoom transform
- Window title / status bar show file name, index, zoom, path

## Sibling list

- Directory of opened file, or chosen folder
- Extensions: `.rpgmvp`, `.png_`, `.png`
- Sort by file name (ordinal ignore-case)
- Left / Right cycle

## Acceptance

1. File → 打开图片 / 打开文件夹 works
2. Wheel and Ctrl+/- zoom; View presets apply
3. Help shows about app / author with GitHub link
